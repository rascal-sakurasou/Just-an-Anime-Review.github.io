# Animecia

**Animecia（アニメシア）** は、

> **「次に見るアニメを見つける」**

をコンセプトにした、アニメ情報・検索・レビュー・お気に入り・視聴管理などを提供するWebサービスです。

---

## サービス概要

| 項目 | 内容 |
|---|---|
| サイト名 | Animecia |
| コンセプト | 次に見るアニメを見つける |
| 公開サイト | https://media-mania.github.io/Animecia/ |
| GitHub | https://github.com/media-mania/Animecia |

Animeciaでは、単純なアニメ作品データベースだけではなく、

- 作品情報
- 検索
- 絞り込み
- 人気度
- 評価
- レビュー
- お気に入り
- 視聴状況
- 関連作品
- おすすめ作品

などを組み合わせて、利用者が自分に合った作品を探せるサービスを目指しています。

---

# 主な機能

## アニメ情報

アニメ作品について、以下の情報を管理・表示します。

- 作品タイトル
- ローマ字タイトル
- 英語タイトル
- 日本語タイトル
- 原題
- あらすじ
- キービジュアル
- バナー画像
- 放送開始日
- 放送終了日
- 話数
- 1話あたりの長さ
- 放送ステータス
- 形式
- 放送クール
- 放送年
- 原作
- 平均スコア
- 人気度
- お気に入り数
- 公式サイト
- 外部サービスID

---

## アニメ検索・絞り込み

現在のAnimeciaでは、作品を以下の条件から探せる構成になっています。

- タイトル検索
- 放送年
- 放送クール
- 放送ステータス
- 形式
- 評価順
- 人気順
- 新着順
- タイトル順

今後、以下の検索機能をさらに拡張する予定です。

- ジャンル
- スタジオ
- 原作
- 放送期間
- 作品タイプ
- キャラクター
- スタッフ
- より高度な複合検索

---

# ユーザー機能

アカウントを作成することで、以下の機能を利用できる構成です。

- 新規登録
- ログイン
- ログアウト
- プロフィール
- お気に入り登録
- 視聴ステータス管理
- 視聴進捗管理
- ユーザー評価
- レビュー投稿
- レビューへのいいね

---

## 視聴ステータス

作品ごとに以下の視聴状態を管理します。

- 視聴中
- 視聴完了
- 視聴予定
- 中断
- 一時停止

さらに、作品ごとの視聴進捗も管理します。

---

# レビュー

利用者はアニメ作品に対してレビューを投稿できます。

レビューには以下の情報を保存します。

- レビュータイトル
- レビュー本文
- 評価
- ネタバレ設定
- いいね数
- 投稿日
- 更新日時
- 投稿ユーザー

評価は **1～10** の範囲で管理します。

---

# おすすめアニメ

管理者が選択した作品を、Animeciaのおすすめ作品として掲載できます。

おすすめ設定では、

- 対象作品
- 開始日
- 終了日
- 開始時刻
- 終了時刻
- 表示順
- 公開・非公開

を管理できます。

これにより、期間や時間帯に応じておすすめ作品を切り替えられる構成を目指しています。

---

# 広告

Animeciaではサイト運営のために広告を掲載できるようにしています。

広告管理では以下を扱います。

- 企業名
- 広告タイトル
- 説明
- 画像
- リンク先URL
- 公開・非公開

広告画像はSupabase Storageへの保存を使用します。

# 大量アニメデータの自動登録

Animeciaでは、今後大量のアニメ作品を手動で登録するのではなく、外部アニメデータAPIから自動的に取得・登録する仕組みを構築します。

基本構成は以下を予定しています。

```text
外部アニメAPI
      ↓
データ取得
      ↓
重複チェック
      ↓
作品情報の正規化
      ↓
anime
      ↓
genres / anime_genres
studios / anime_studios
characters / anime_characters
staff / anime_staff
anime_relations
      ↓
Animecia
